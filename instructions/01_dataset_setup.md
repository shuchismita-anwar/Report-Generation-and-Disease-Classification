## Required Datasets

### 1. MIMIC-Eye Dataset

**Location:** Root folder

```
.\mimic-eye-integrating-mimic-datasets-with-reflacx-and-eye-gaze-for-multimodal-deep-learning-applications-1.0.0\mimic-eye
```

**Description:** Main dataset containing chest X-rays with eye-gaze data, bounding boxes, and transcripts.

### 2. Dataset Splits

**Location:** `.\dataset_splits\` (in root folder)

**Required Structure:**

```
dataset_splits/
├── train/
├── val/
└── test/
```

**Description:** Split datasets with appropriate train/validation/test naming convention for model training.

### 3. Final Dataset CSV

**Required File:** `.\final_dataset_fixed.csv` (root folder)

**Usage:** Used by `.\scripts\preprocess.py` to generate required data dumps.

### 4. Preprocessed Data (Generated)

**Location:** `.\data_dump\output\` (root folder)

**Contents:**

- `bbox_mask/` - Bounding box mask data
- `fix_seq/` - Fixation sequence data
- `img_png/` - Processed PNG images

**Generation:** Run `.\scripts\preprocess.py` to create these folders from `final_dataset_fixed.csv`

### 5. Fixation Statistics

**Required File:** `.\fixstats.npz` (root folder)

**Description:** Generated by preprocessing script, contains fixation statistics.

### 6. Ground Truth Reports

**Location:** `.\cleaned_reports\` (root folder)

**Description:** Contains ground truth medical reports for evaluation purposes.

## Setup Steps

1. **Download MIMIC-Eye Dataset**

   - Place in: `.\mimic-eye-integrating-mimic-datasets-with-reflacx-and-eye-gaze-for-multimodal-deep-learning-applications-1.0.0\mimic-eye`

2. **Prepare Dataset Splits**

   - Create `.\dataset_splits\` folder with train/val/test subfolders
   - Organize your split data accordingly

3. **Run Preprocessing** (if data_dump not provided)

   - Ensure `.\final_dataset_fixed.csv` is in root folder
   - Run: `.\scripts\preprocess.py`
   - This generates:
     - `.\data_dump\output\bbox_mask`
     - `.\data_dump\output\fix_seq`
     - `.\data_dump\output\img_png`
     - `.\fixstats.npz`

4. **Verify Structure**
   ```
   Root/
   ├── mimic-eye-integrating-mimic-datasets-with-reflacx-and-eye-gaze-for-multimodal-deep-learning-applications-1.0.0/
   │   └── mimic-eye/
   ├── dataset_splits/
   │   ├── train/
   │   ├── val/
   │   └── test/
   ├── data_dump/
   │   └── output/
   │       ├── bbox_mask/
   │       ├── fix_seq/
   │       └── img_png/
   ├── cleaned_reports/
   ├── final_dataset_fixed.csv
   └── fixstats.npz
   ```

## Data Dependencies

- All training scripts require the preprocessed data in `.\data_dump\output\`
- Inference scripts require the image data in `.\data_dump\output\img_png`
- Evaluation scripts require ground truth reports in `.\cleaned_reports\`
